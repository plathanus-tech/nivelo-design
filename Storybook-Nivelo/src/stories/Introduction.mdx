# Nivelo Design System

Bem-vindo ao **Nivelo Design System** — a biblioteca de componentes e tokens de design que padroniza a experiência visual dos produtos Nivelo.

## O que você encontra aqui

- **Foundations** — Paleta de cores, tipografia e espaçamentos
- **Components** — Componentes React prontos para uso, com suporte a dark mode e acessibilidade

## Design Tokens

Todos os componentes utilizam [CSS custom properties](https://developer.mozilla.org/en-US/docs/Web/CSS/--*) definidas em `src/tokens/tokens.css`.
Importe o arquivo de tokens antes de usar qualquer componente:

```tsx
import '@nivelo/design-system/tokens.css';
```

## Tipografia

| Fonte | Peso | Uso |
|-------|------|-----|
| **Helvetica Neue** | Medium (500) | Headings (h1–h6) |
| **Helvetica Neue** | Light (300) | Body, UI, textos corridos |

## Paleta de cores

| Cor | RGB | Uso |
|-----|-----|-----|
| **Brand Blue** | 23, 82, 176 | Cor principal — botões, links, ações |
| **Accent Gold** | 239, 203, 52 | Destaques pontuais apenas |
| **White** | 255, 255, 255 | Superfícies e fundos |
