Breakpoints

O sistema é mobile-first: os estilos base são para telas pequenas e os breakpoints aumentam progressivamente. Use os tokens CSS custom properties ou as media queries abaixo nos componentes.

Escala de breakpoints

sm480pxTelefone grande4
md768pxTablet8
lg1024pxDesktop pequeno / laptop12

2xl1536pxDesktop largo12
CSS Custom Properties
/* tokens de breakpoint — use em JS e media queries */
:root {
  --bp-sm: 480px;
  --bp-md: 768px;
  --bp-lg: 1024px;
  --bp-xl: 1280px;
  --bp-2xl: 1536px;
}

/* mobile-first media queries */
@media(min-width: 768px) { /* tablet+ */ }
@media(min-width: 1024px) { /* desktop+ */ }

Button

Aciona uma ação imediata. Use Primary para a ação principal, Secondary para ações secundárias, Ghost para ações terciárias. Accent apenas em CTAs de destaque máximo.

✓ WCAG 2.1 AA ✓ Keyboard navigable ✓ Focus visible ✓ Disabled state ℹ Use type="button" fora de forms

Input

Campo de texto. Todo input deve ter um <label> associado via for/id — nunca use apenas placeholder como label.

✓ Label obrigatória ✓ aria-describedby para hints ✓ aria-invalid no estado de erro ✓ Focus visible
Default
Conforme documento oficial 
<div class="field">
  <label class="field-label" for="inp">Nome completo</label>
  <input class="input" id="inp" type="text"
         placeholder="Ex: João Silva"
         aria-describedby="inp-hint"/>
  <span class="field-hint" id="inp-hint">Conforme documento oficial</span>
</div>
Estados
E-mail inválido 
<!-- Erro -->
<input class="input err-state" type="email"
       aria-invalid="true" aria-describedby="msg"/>
<span id="msg" role="alert">E-mail inválido</span>

<!-- Desabilitado -->
<input class="input" disabled aria-disabled="true"/>

Feedback / Alert

Mensagens de feedback contextual. Use role="alert" para mensagens que surgem dinamicamente — o leitor de tela as anuncia automaticamente.

✓ role="alert" para erros ✓ role="status" para info/sucesso ✓ Ícone com aria-hidden ✓ Contraste AA garantido
Variantes
Informação — Sua solicitação está sendo processada.
Sucesso — Dados salvos com sucesso.
Atenção — Esta ação não pode ser desfeita.
Erro — Não foi possível completar a operação.
<div class="alert alert-error" role="alert">
  <span aria-hidden="true">🚫</span>
  <div><strong>Erro</strong> — Mensagem.</div>
</div>

Navegação entre conteúdos relacionados no mesmo nível. Use role="tablist", role="tab" e role="tabpanel".

✓ role="tablist/tab/tabpanel" ✓ aria-selected ✓ aria-controls / aria-labelledby ✓ Keyboard: ←→ para navegar

Accordion

Exibe e oculta conteúdo sob demanda. Use aria-expanded no botão e aria-controls apontando para o painel.

✓ aria-expanded no botão ✓ aria-controls / id no painel ✓ Keyboard: Enter/Space

Tooltip

Informação complementar ao hover/focus. Nunca coloque conteúdo essencial só no tooltip — o usuário pode não descobri-lo.

✓ role="tooltip" ✓ aria-describedby no trigger ✓ Visível no foco do teclado ⚠ Não use para conteúdo essencial
Default

Abrir documentação

  2. /
  3. Financeiro

</nav>
